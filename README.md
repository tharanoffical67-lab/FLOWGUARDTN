# FLOWGUARD TN

### AI-Assisted Hospital Crowd Prediction & Patient Flow Coordination

FLOWGUARD TN is a hackathon prototype designed to help reduce hospital overcrowding and improve patient navigation in Tamil Nadu government hospitals.

## Live Website

🚀 [Open FLOWGUARD TN](https://hackathon-spark-foundry.lovable.app)

## Proposed Features

- Patient registration and token generation
- Hospital queue monitoring
- Doctor availability and room guidance
- Hospital navigation
- Staff dashboard
- Tamil and English language support

## Technology

- AI-assisted website development
- Web application frontend
- Optional backend and database integration

## Project Status

Hackathon prototype. Sample information and hospital locations are illustrative and must be verified before real-world use.
